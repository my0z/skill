# movie-trailer

사진 2~3장 + 영상 1개를 24초 안팎의 시네마틱 예고편 mp4로 만든다.
렌더링은 같은 폴더의 `trailer.sh`(ffmpeg만 사용)가 맡고 Claude는 연출을 맡는다.

## 순서

1. 입력 확인. 사진 2~3장과 영상 1개가 아니면 사용자에게 다시 요청한다.
2. Read 도구로 사진을 직접 보고 분위기를 파악한다.
3. 연출 결정
   - 사진 순서: 가장 조용한 장면 먼저 가장 강한 장면 마지막
   - 태그라인(`-g`): 15자 이내 한 문장 긴장감 있게
   - 제목(`-t`): 10자 이내
   - 엔딩 문구(`-c`): 기본 `COMING SOON` 또는 날짜
4. 음악(선택). Artlist MCP의 `generate_music`이 연결돼 있으면 "epic cinematic trailer 30s" 같은 프롬프트로 만들어 받은 파일을 `-m`으로 넘긴다. 없으면 내장 드론과 컷 붐 사운드를 쓴다.
5. 실행
   ```
   ~/.claude/skills/movie-trailer/trailer.sh -t "제목" -g "태그라인" -o trailer.mp4 사진1 사진2 [사진3] 영상
   ```
6. 확인. 아래 명령으로 콘택트 시트를 만들어 Read로 보고 이상하면 순서나 문구를 바꿔 다시 렌더한다.
   ```
   ffmpeg -y -i trailer.mp4 -vf "fps=1/3,scale=480:-1,tile=4x2" -frames:v 1 sheet.png
   ```
7. 결과 mp4를 사용자에게 전달한다(SendUserFile이 있으면 그것으로).

## 구성 (3초 단위)

태그라인 카드 → 사진1 줌인 → 영상 20% 지점 → 사진2 줌인 → 영상 70% 지점 → 사진3 줌인 → 제목 카드 → 엔딩 카드

모든 컷에 틸오렌지 그레이딩 비네팅 2.39:1 레터박스 페이드가 들어가고 오디오는 -14 LUFS로 맞춘다.

## 필요

ffmpeg / bc / 한글 폰트(fonts-nanum 등). 저장소 `install.sh`가 없으면 설치한다.
