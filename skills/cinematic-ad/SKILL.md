# cinematic-ad

상품 사진 2~3장 + 영상 1개를 17~23초 길이의 시네마틱 상품광고 mp4로 만든다.
렌더링은 같은 폴더의 `ad.sh`(ffmpeg만 사용)가 맡고 Claude는 광고 연출과 카피를 맡는다.

## 순서

1. 입력 확인. 사진 2~3장과 영상 1개가 아니면 사용자에게 다시 요청한다. 상품명과 브랜드 주소를 모르면 한 번에 물어본다.
2. Read 도구로 사진을 직접 보고 상품의 종류와 소재와 분위기를 파악한다.
3. 연출 결정
   - 사진 순서: 디테일 컷 먼저 / 상품 전체가 잘 보이는 사진을 마지막(히어로 샷)에 둔다
   - 훅 카피(`-g`): 15자 이내. 상품이 아닌 감정이나 상황으로 시작 (예: "소리가 사라지는 순간")
   - 상품명(`-n`): 히어로 샷 위와 엔딩에 표시
   - 슬로건(`-s`): 20자 이내 상품의 핵심 가치 하나
   - CTA(`-c`): 사이트 주소나 출시일
4. 음악(선택). Artlist MCP의 `generate_music`이 연결돼 있으면 상품 분위기에 맞는 "cinematic commercial 25s" 프롬프트로 만들어 받은 파일을 `-m`으로 넘긴다. 없으면 내장 드론과 컷 히트 사운드를 쓴다.
5. 실행
   ```
   ~/.claude/skills/cinematic-ad/ad.sh -n "상품명" -g "훅 카피" -s "슬로건" -c "brand.com" -o ad.mp4 사진1 사진2 [사진3] 영상
   ```
6. 확인. 콘택트 시트를 만들어 Read로 보고 상품이 잘리거나 글자가 겹치면 순서나 문구를 바꿔 다시 렌더한다.
   ```
   ffmpeg -y -i ad.mp4 -vf "fps=1/3,scale=480:-1,tile=4x2" -frames:v 1 sheet.png
   ```
7. 결과 mp4를 사용자에게 전달한다(SendUserFile이 있으면 그것으로).

## 구성

훅 카피(3초) → 사진1 푸시인(3초) → 영상 20% 지점(3초) → 사진2 푸시인(3초 / 사진 3장일 때) → 영상 70% 지점(3초) → 히어로 샷 줌아웃 + 상품명(4초) → 엔딩 상품명 + 슬로건 + CTA(4초)

상품 색이 변하지 않게 대비와 따뜻한 톤만 살짝 올리고 약한 비네팅과 2.39:1 레터박스와 페이드를 넣는다. 오디오는 -14 LUFS로 맞춘다.

## 필요

ffmpeg / bc / 한글 폰트(fonts-nanum 등). 저장소 `install.sh`가 없으면 설치한다.
